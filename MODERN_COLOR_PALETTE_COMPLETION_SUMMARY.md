## 🎨 Color System Details

### Primary Colors (Blue)
- Light mode: `#3B82F6` (blue-600) for primary actions
- Dark mode: `#60A5FA` (blue-400) for better contrast
- Full scale: 50-900 with semantic naming

### Secondary Colors (Purple)
- Light mode: `#8B5CF6` (violet-600) for secondary actions
- Dark mode: `#A78BFA` (violet-400) for dark mode compatibility
- Used for accent elements and secondary CTAs

### Accent Colors (Orange)
- Light mode: `#F59E0B` (amber-600) for highlights
- Dark mode: `#FBBF24` (amber-400) for visibility
- Used for ratings, badges, and attention-grabbing elements

### Semantic Colors
- **Success**: Green palette for completed states, success messages
- **Warning**: Amber palette for caution states, pending actions
- **Error**: Red palette for error states, destructive actions
- **Info**: Cyan palette for informational content

### Neutral Colors
- Warm gray palette for text, backgrounds, and borders
- Properly inverted for dark mode
- Ensures excellent readability and contrast
